# US-Law-Study｜美国法律学习笔记

一个普通人在美国生活、工作，一边处理真实的法律事务，一边把学到的东西记下来的仓库。这里没有速成课，也没有大道理，就是按主题整理的学习笔记：备考要点、判例拆解、日常会用到的常识，还有一张慢慢补全的美国法律体系地图。

每篇文章都是三语对照：中文为主，英文次之，西班牙语为学习译稿。同一文件内按小节排三个版本，方便对照着读。

作者：Guangyi Zhao

备考和实务流程类笔记，把条文和程序拆成能一步步照着核对的清单。

- [美国律师资格考试：UBE、各州差异与加州律师考试深挖](法律备考/美国律师资格考试-UBE与加州考试深挖.md) —— UBE 三部件权重、各州通过线、加州两天制与 1390 分通过线、MPRE 86 分与品行审查。

- [侵权法备考核心：过失、故意与严格责任](法律备考/侵权法备考核心-过失故意与严格责任.md) —— 先分故意、过失、严格责任三条线，再拆过失四要素：Palsgraf（248 N.Y. 339）的义务边界、negligence per se 与 res ipsa、事实因果与近因、蛋壳头骨规则，以及 Li v. Yellow Cab（13 Cal.3d 804）确立的加州纯粹比较过失与 § 1431.2 非经济损害按份责任。

### 案例分析
经典判例拆解：事实、争点、判决、推理，一篇一个案子。

- [Gideon v. Wainwright (1963) 案例分析](案例分析/Gideon-v-Wainwright-1963-案例分析.md) —— 请不起律师时州必须免费指派：第六修正案律师帮助权如何经第十四修正案落到各州，以及 Argersinger、Scott、Strickland 划出的后续边界。

- [Marbury v. Madison (1803) 案例分析](案例分析/Marbury-v-Madison-1803-案例分析.md) —— 司法审查的源头：5 U.S. (1 Cranch) 137 里 Marshall 的三问结构、1789 年《司法法》第 13 条与宪法第三条的冲突，以及法院靠拒绝行使一项权力确立更大权力的悖论。
