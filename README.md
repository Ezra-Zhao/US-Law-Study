# US-Law-Study｜美国法律学习笔记

一个普通人在美国生活、工作，一边处理真实的法律事务，一边把学到的东西记下来的仓库。这里没有速成课，也没有大道理，就是按主题整理的学习笔记：备考要点、判例拆解、日常会用到的常识，还有一张慢慢补全的美国法律体系地图。

每篇文章都是三语对照：中文为主，英文次之，西班牙语为学习译稿。同一文件内按小节排三个版本，方便对照着读。

作者：Guangyi Zhao

Perry（570 U.S. 693）以当事人资格驳回后于 2013 年先行恢复登记，Obergefell 于 2015 年推向全国，2022 年《尊重婚姻法》（Pub. L. 117-228）再补 1 U.S.C. § 7 与 28 U.S.C. § 1738C 的法定承认层（本身不课各州发证义务）。（六语对照）
